# Ritaj Alharbi — Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example: `ritaj-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. After GitHub finishes publishing, your site will be available at:
   `https://YOUR-USERNAME.github.io/ritaj-portfolio/`

The CV is included in `assets/Ritaj_Alharbi_CV.pdf`.

# Ritaj Alharbi — AI Engineer Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of your `portfolio` repository.
2. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
3. Your site will publish at `https://callretaj.github.io/portfolio/`.

## Add project images
Upload your images into `assets/projects/` using the exact names listed in `assets/projects/HOW_TO_ADD_IMAGES.txt`. Each project has an independent image carousel with next/previous arrows and dots.

## Files
- `index.html` — page content
- `style.css` — layout and styling
- `script.js` — theme, mobile navigation, reveal effects, and project image carousels
- `assets/` — CV and project images


## Add project files
Upload these PDFs to `assets/projects/` using the exact names below:
- `haden.pdf` for the Haden project
- `nabatron.pdf` for the Nabatron project
The project cards already link to these paths. If your file is PowerPoint instead, update the `.pdf` extension in the two links in `index.html` to `.pptx`.


## Project image filenames
Upload three images for each project into `assets/projects/` using these exact names:
- Haden: `haden-1.jpg`, `haden-2.jpg`, `haden-3.jpg`
- Pneumonia: `pneumonia-1.jpg`, `pneumonia-2.jpg`, `pneumonia-3.jpg`
- Nabatron: `nabatron-1.jpg`, `nabatron-2.jpg`, `nabatron-3.jpg`

Each project has its own independent image carousel with arrows and dots.
